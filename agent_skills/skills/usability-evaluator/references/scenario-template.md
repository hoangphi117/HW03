## Success Criteria

The task is considered **complete** when:
- [ ] Participant has placed at least one order successfully (order confirmation displayed).
- [ ] Participant can locate the placed order in the Order History screen.

The task is considered **partial** when:
- Participant reaches checkout but abandons before confirming.

The task is considered **failed** when:
- Participant cannot add an item to cart after 5 minutes, or explicitly gives up.
